# 辅助监督均衡与受控比较 · 2026-11-05

本研究针对两个问题：同题 centered 目标对不同类别的覆盖不同；更新外部文本时，同题伙伴和二/三行组比例也一起变化。当前方案固定跨数据条件的辅助上下文，并独立归一化目标类别的辅助损失预算。已完成真实数据与采样分析，尚无新模型 BA；损失系数的平衡不等于梯度范数、信息量或预测收益的平衡。

分析使用题目风险隔离后的 baseline/mix20，各 119,861 条，72 个类别×长度桶完全一致。官方 2,699 条与五折不变。本次只改变辅助监督与比较条件，没有重新筛选训练数据。

## 覆盖差异的来源

原计划按各池独立组成三行同题组，剩余两类组成二行组。两轮平均覆盖如下：

| 类别 | baseline | mix20 |
|---|---:|---:|
| Fable | 77.09% | 76.23% |
| Gemini 3.7 Flash | 89.04% | 86.36% |
| Kimi K3 | 96.58% | 91.51% |
| Astra | 97.78% | 97.80% |

Fable 有异类同题伙伴的文本比例本身只有 80.55% / 79.85%，Astra 为 99.14% / 99.46%。缺失的同题伙伴不能通过加权或重排凭空补齐。三行优先贪心还会浪费部分配对机会，例如类别计数为 `[2,1,1]` 的组先取三行后剩一行，而两个二行组可以覆盖四行。允许二/三行且不重复文本时，每组最多覆盖 `min(N, 2 × (N − max_class_count))` 条。全池的相应上限为 94.70% / 94.82%，比现有计划多 2,702 / 2,886 条；即使达到这个上限，类别间的结构性供给差异仍存在。

两池共有 96,747 条相同正文，其中 94,861 条具有一致 prompt 且双方均可用于同题监督；多标签共同组覆盖 91,730 条、7,403 组。原计划第一轮完全相同的 centered 批只有 1,897 组、5,066 条。因此，仅保持总体覆盖约 92.4%，不足以把两池分数差解释为新增文本质量。[原方案诊断](../runs/q8_centered_20261105/diagnosis/summary.json) · [逐类与组大小损失系数](../runs/q8_centered_20261105/diagnosis/class_size_loss_mass.csv)

## 固定关系上下文

新方案仅从两池共同正文、相同标签与 prompt、双方均 eligible 的行构造同题不同标签三行组。每个 epoch 的辅助正文、同伴、批次顺序、所在更新窗口及窗口行数在 baseline/mix20 间相同。其余行全部进入 plain 混合批，每条文本仍参与一次 plain CE，没有为了填组复制文本。

官方阶段在每个外层训练折内单独构造三行组，不使用验证折。关闭 centered 只令其强度为零，保留相同批次布局和头部 dropout 调用。这样同一数据条件的 off/on 不因开关额外改变随机数消耗；跨数据条件的 padding 长度仍可能不同，不能承诺整个模型随机轨迹逐值相同。

| 修复后外部计划，每轮 | baseline | mix20 |
|---|---:|---:|
| plain 文本 | 119,861 | 119,861 |
| plain 遗漏 / 重复 | 0 / 0 | 0 / 0 |
| 共同三行组 | 28,165 | 28,165 |
| centered 文本 | 84,495 | 84,495 |
| centered 覆盖 | 70.4942% | 70.4942% |
| 优化更新 | 6,659 | 6,659 |

固定共同三行组降低了辅助覆盖：首轮 Fable 为 59.91%，Astra 为 74.80%，两池逐类覆盖相同。它放弃了独有关系样本和二行组，以控制比较条件；所有这些文本仍保留 plain 训练。这是一项明确的研究取舍，不是把 Fable 的物理覆盖提升至 98%。[共同组供给](../runs/q8_centered_20261105/diagnosis/shared_triplets_summary.json)

## 独立辅助损失预算

令 `w_i` 为当前 plain 行权重，`n_u` 为其优化窗口的真实行数，`A_c` 为本 epoch 实际执行预算内、目标标签为 c 的辅助行集合。先计算

`S_c = Σ(i∈A_c) w_i / n_u`。

若该 epoch 实际执行 U 次更新，类别平衡系数取

`a_c = (U / 18) / S_c`，`w_centered_i = a_c × w_i`。

窗口损失为 `Σ w_i × CE_plain_i / n_u + λ × Σ w_centered_i × CE_centered_i / n_u`。因此每类累计辅助损失系数为 `λU/18`，总量为 `λU`，不依赖该类覆盖率或窗口是否正好含 18 行。plain 权重保持原定义。matched 仍使用训练折拟合的类内软权重形状，随后单独校准各类辅助预算。

默认 λ=1。外部每类每轮目标为 `6659/18 ≈ 369.94444`；实际 float32 系数与目标之差小于 0.00002。baseline/mix20 两轮补偿倍率为 1.31766–1.66913，每类系数 ESS 比例至少 99.998%。baseline/mix20 的逐行辅助系数完全相同。Fable 与 Astra 物理覆盖仍不同，但目标类别辅助预算已一致；中心化均值使一条损失也向同伴传播梯度，不能将此结论扩大为各类梯度相等。

若直接比较不加权共享组与类别平衡，还会同时改变辅助总强度。因此保留 `global_mass` 对照：所有辅助行统一乘 `U/ΣS_c`，总量同为 U、保留类别份额偏斜。`global_mass` 与 `class_mass` 的同数据比较才把重平衡与总强度区分开。原 `native + none` 作为历史参照保留，首轮总辅助系数分别约 6,161.23 / 6,149.57；不能把它与新方案的差异全部归因为类别重平衡。

部分预算按每个实际活跃 epoch 的前缀重新校准，改变预算也改变相应权重，不能声称短前缀与完整训练使用完全相同的目标。实际 100 次更新覆盖 1,800 行、辅助 1,209 行，各类系数为 `100/18`；λ=0.25 时总辅助系数为 25。若活跃前缀缺少某类辅助支持，则该类 `S_c=0`，18 类均衡没有定义，不能加极小常数伪造支持。关闭辅助时则允许该前缀，实际辅助系数为零。[实际计划、权重的独立核验](../runs/q8_centered_20261105/final_plan_verification.json) · [逐类覆盖与系数](../runs/q8_centered_20261105/final_plan_verification_classes.csv)

## 数据与辅助监督的四格比较

核心实验在相同切分、底座和预算下比较：A0=baseline/off、B0=mix20/off、A1=baseline/shared-balanced、B1=mix20/shared-balanced。每格各自建立外部起点，再按同样的辅助条件适配官方五折；不能只在官方阶段切换开关，却将结论解释为完整两阶段的辅助作用。

- `B0 − A0`：关闭辅助时的文本更新效果。
- `B1 − A1`：固定共同辅助监督条件下的文本更新效果。
- `A1 − A0`、`B1 − B0`：各数据条件下辅助目标的作用。
- `(B1 − A1) − (B0 − A0)`：文本更新与辅助目标的交互。

四格的整体 BA、逐类、长度桶、逐折差值和按 prompt 配对重采样的交互区间应一起报告。平衡作用另用同数据的 shared/global 与 shared/class 比较。固定输入关系上下文之后，模型表示和梯度仍会随训练改变，因此上述差值是给定方法下的条件效应，不能称为普遍的“纯文本质量”。

目前已实测的是训练行、采样计划、窗口、损失系数以及五个官方训练折的完整性；四格尚无新 Q8 模型 OOF，不能填入 BA 或声称提分。新增方案也未解决正文聚类误差、训练三行组与部署稀疏组的差异，或公共外部池的上游筛选历史，这些仍需独立研究。
