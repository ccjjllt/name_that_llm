# Kimi 与 GLM 的跨推理档位一致性

同型号输出的排版可能随推理档位变化。在上一轮的 Kimi 158 对可比回答中，关闭推理后平均只短 1.04 词，分号出现率降低 31.0 个百分点。本次比较普通分类与同一型号跨档位一致性训练，检验后者能否让专家在不同来源的短文上保留型号信号。[前轮档位分析](../runs/current_frontier_20261124/protocol_signal.json)

## 数据和训练

- 从 Open Pool v18 选 **245 对、490 篇**真实生成，涉及 209 个规范题组和两个训练来源。每对同来源、规范题、型号、报告路由及返回型号，推理档位不同。两篇相差至多 12 词，长短比至多 1.15。排除两种公开代理标记、官方题重建和已知风险路由。实际发出的请求字节可能不同。
- 训练配对中，Kimi‑K3 199 对，GLM‑5.3 26 对，GLM‑5.3‑Flash 20 对。每轮保留全部配对，重复少数类使三类各有 199 对，按相同种子抽样和排序。两臂共用 Qwen3‑4B Base 前 20 层、末 8 层的 rank‑8 LoRA、相同初始化及 4 轮日程，每臂计划 300 步。普通臂用三类交叉熵，另一臂在此基础上加入权重 0.50 的对称 KL，缩小同一型号两种档位下的分类分布差异。模型预测只读单篇正文。
- 留出 Arxitekton 整个发布者，排除其验证题组。两边训练和留出正文、题组及来源均无重合。留出含 **77 对、154 篇、28 个规范题组**，其中 72 篇不足 100 词，GLM Full、Flash、Kimi 分别为 30、20、22 篇。留源正文在 Open Pool v18 中，对本次新专家按来源留出。原版底座曾使用该语料，另通过复跑的正文比对记录重合数量。面板每对来自同一个型号与题目，既有底座可见重复作者，两臂共用同一份逐条底座分数。

## 同底座评估

只在不足 100 词、原首选为三目标类之一且候选在原底座前三时允许重排。原 GLM 首选行使用 GLM 阶段分数，其余行用族内残差分数。保留 Fable 和排版保护。候选须得到专家正方向支持，专家分差截断至 ±3，再同底座分差比较。两臂预先固定 0.35 主权重，并附 0、0.15、0.70 同权对照。权重不根据留源表现选择。

旧 C1、C2 的短文没有三类真值，三候选以内的改判无法在这两组提高 BA。重建压力集有 37 条 Kimi 短文，缺两种 GLM。留源短文含三个目标真类，是判断跨档位训练是否增加正确数和 BA 的主要面板。每组保留对原版及两臂相互比较的改对数、改错数、净数、BA 与按题重采样区间。另检查按档位及来源的召回和同题两篇均判正确的次数。[复算实现](../src/ntllm/effort_pair_report.py)

## 实测结果

两臂使用同一份 245 对训练样本，实际各完成 300 步且无跳步。下载的 798 条公开轨迹评估与本地复算一致。留源的 154 条正文逐条通过 ID 与正文哈希校验，其中 154 条与本次原版底座使用的活动 Open Pool 完全重合，官方训练正文重合 0 条。Arxitekton 的独立性适用于新专家训练。[逐条结果](../runs/effort_pair_20261124/audit/paired_predictions.parquet) · [复算报告](../runs/effort_pair_20261124/audit/report.json)

| 短文面板 | 原版 BA | 普通分类 BA | 跨档位一致性 BA | 一致性相对普通改对 / 改错 / 净数 |
|---|---:|---:|---:|---:|
| C2，153 条 | 62.18% | 62.18% | 62.18% | 0 / 0 / 0 |
| 重建压力，160 条 | 40.95% | 42.98% | 42.98% | 0 / 0 / 0 |
| Arxitekton 留源，72 条 | 45.45% | 36.01% | 36.57% | 1 / 1 / 0 |

主权重 0.35 下，两臂在 C2 均把同一条真 Opus 4.6 从 GLM Full 改成 Kimi，改判前后均错。压力集的两臂都把同样 3 条真实 Kimi 从 GLM Flash 改对，均无新增错误。Kimi 短文召回 **17/37 → 20/37**。权重 0.15 和 0.70 时，两臂也分别得到相同的 1 条和 4 条净收益。

留源上，两臂相对原版均改对 0 条、改错 7 条，正确总数从 34 降至 27。一致性比普通分类多判对 1 条 Flash，同时少判对 1 条 Full。由于样本支持量分别为 20 和 30，BA 差值为 **+0.56 个百分点**，按题重采样的 95% 区间为 **−2.94 至 +4.58**。一致性在 0.15 与 0.70 权重下相对普通分类均多错 1 条，三个非零权重下均低于原版。独立留源中，一致性专家的单独预测召回为 GLM Full 0/30、GLM Flash 1/20、Kimi 22/22。相同的 Kimi 改判及留源的 GLM 退化，缺乏提交三类专家的依据。[改判明细](../runs/effort_pair_20261124/audit/changed_rows.parquet)
