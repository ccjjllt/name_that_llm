# q8 训练方案与数据实验

研究目标是提高现有 0.668 集成中 q8 成员的贡献。当前以 q8v5 的发布结构重建一个训练历史明确的参照，优先研究可信新文本与折内软分布匹配。原作者的训练源码、Stage 1 权重和精确分折仍缺证据，因此本项目的优化设置和分折采用明确的研究选择。[原配方证据](../runs/q8v5_research_20261105/recipe/recipe-evidence.md)

| 部分 | 本项目方案 | 依据 |
|---|---|---|
| 底座 | Qwen3-8B-Base 前 24 层 | q8v5 发布推理 |
| LoRA | rank 16、alpha 32、dropout 0.05，q/k/v/o 与 gate/up/down 投影 | 已发布 adapter 配置 |
| 表示 | 第 2/4/6/8/12/16/20/24 层均值池化，各层 LayerNorm 后拼接 | q8v5 发布推理 |
| 文本 | 最多 384 token，保留原大小写、标点与换行，沿用 tokenizer 默认特殊 token 行为，保留末端 norm | q8v5 发布推理 |
| 训练目标 | 全 18 类 plain CE，共同三行组增加独立类预算的 centered CE | 两头方法来自公开方案；共享组与独立预算为本项目修复 |
| 训练阶段 | 外部池两轮，再在官方训练折上两轮 | 作者报告 |
| 官方阶段学习率 | LoRA 5e-5，分类头和 LayerNorm 5e-4 | 作者报告的 adapter/head LR |
| 外部阶段学习率 | LoRA 1e-4，分类头和 LayerNorm 1e-3 | 本项目重建选择 |
| 其他优化条件 | AdamW，weight decay 0.01，10% warmup 后 cosine，head dropout 0.1，梯度裁剪 1.0 | 本项目重建选择 |
| 类别权重 | plain 按当前训练数据计算 `N / (18 × n_class)`；centered 按实际窗口校准每类总系数 | 本项目重建选择 |

作者报告 q8v5 的五折 OOF 为 0.614，逐行预测和具体分支计分口径仍待取得。该分数用于判断研究方向，当前新配方的效果需要后续模型实验。[作者方案](https://www.kaggle.com/code/dhruvtibarewal/name-that-llm-fully-reproducible) · [已发布配置](../runs/q8v5_research_20261105/artifacts/final/adapter_config.json)

**数据参照与新增文本。** 原始输入池为 119,899 条、18 类。此前与筛选后的 Open Pool v14 比较，共有 97,593 条相同正文与标签，113,681 条文本为新版新增，22,306 条旧文本缺于新版。共同正文的标签冲突为零。新版缺失不等于质量不合格；当前对原、新池统一做题目风险隔离，原池排除 38 条后保留 119,861 条，作为新的 baseline。下表及训练计划均使用这一修复后数据条件。[原池](https://www.kaggle.com/datasets/dhruvtibarewal/nlm-matched-clean/versions/3) · [原始版本差异](../runs/q8v5_research_20261105/data/comparison.json) · [隔离前后比较](../runs/q8_isolation_20261105/analysis.json)

新增实验在每个模型与长度桶内最多替换 20% 文本，供应不足时减少替换。长度桶为小于 60、60–99、100–159、至少 160 词。新增样本优先按可信 canonical 组选择，保留的旧文本优先覆盖这些同题组。20% 是控制首轮改动幅度的选择，效果仍需比较。

| 数据实验 | 唯一文本 | 新于原池的文本 | 类别×长度桶数量 |
|---|---:|---:|---|
| baseline | 119,861 | 0 | 隔离后原池分布 |
| mix20 | 119,861 | 23,114，约 19.284% | 与 baseline 完全一致 |

这保留了原池中部分更贴近目标的分布。例如 Fable 短文本比例在隔离后原池为 20.74%，官方为 20.81%，整池替换为新版会降到 16.10%。本次受控更新维持隔离后参照的类别与长度配额，将首轮问题集中到新增文本是否提供有效信息。[当前数据统计](../data/q8/manifest.json)

**同题监督与文本覆盖。** 两组采用相同分组规则。共同文本可使用新版强 canonical 证据，旧键只有在对应单一 canonical 时才传播映射。有效旧键可作为 legacy 同题组，空键、空后缀和未能消除的歧义使用独立行组。`w_host` 的原训练用法尚未知，本项目仅保留其来源信息。该分组方案属于共同的重建条件。

当前默认只使用 baseline/mix20 共同正文、相同 prompt 且双方 eligible 的三行不同标签组进行 centered 监督，固定两组的正文、同伴和窗口位置。其余文本进入 plain CE 混合批，尾批完整保留；每条文本每轮参与一次 plain。官方阶段仅在当前训练折内构造三行组。同题表示减去组均值后进入 centered 头，目标仍覆盖全部 18 类。原先各池独立生成二/三行组的 `native` 计划保留为参照。[辅助监督修复依据](centered-supervision.md)

| 实际训练计划 | 每轮曝光 | 遗漏 / 重复 | centered 文本覆盖 | 每轮优化更新 |
|---|---:|---:|---:|---:|
| baseline 外部池 | 119,861 | 0 / 0 | 70.494% | 6,659 |
| mix20 外部池 | 119,861 | 0 / 0 | 70.494% | 6,659 |
| 官方 fold 0 训练侧 | 2,159 | 0 / 0 | 99.907% | 120 |

两组外部计划使用相同批大小布局与窗口分母，每个窗口约 18 条文本，当前外部阶段及官方 fold 0 均为 15–20 条。plain 按真实窗口行数归一化，centered 则另行校准每类累计损失系数为 `λ × 该 epoch 实际更新数 / 18`，默认 λ=1。两轮完整覆盖和相同辅助上下文均已由真实计划核对。隔离后旧 native 的约 92.4% 覆盖属于原监督条件；隔离前每轮 6,662 次更新属于旧数据条件。[当前监督计划核验](../runs/q8_centered_20261105/final_plan_verification.json) · [隔离前后采样比较](../runs/q8_isolation_20261105/analysis.json)

**固定池上的软匹配。** matched 使用 baseline 的全部文本，保持逐轮覆盖，只改变类内损失权重。目标统计来自当前官方外层训练折，特征为四个长度桶，以及弯引号、破折号、冒号和换行四项二值排版特征。各边际采用 Laplace 平滑，将密度比几何平均后以 0.5 强度收缩，再归一化为类内均值 1、范围 0.5–2 的权重。

这套平滑权重是本项目候选算法。它控制每类总权重，同时保留文本与来源多样性。训练折中稀少的风格特征不会被直接转成删样本规则。模型 BA 与最终融合收益仍需实测。

fold 0 的目标仅使用训练侧 2,159 条、120 个 prompt。隔离后 baseline 的权重范围为 0.715–1.112，最低类别有效样本量比例为 98.66%，宏平均长度分布总变差距离从 0.06251 降至 0.05776。18 类中 17 类的长度差异减小。这表明匹配适度改变了目标相关分布，尚不能据此推断分类分数。[当前匹配分析](../runs/q8_isolation_20261105/plan_summary.json) · [隔离前五折分布分析](../runs/q8_local_20261105/matching_folds.csv)

**训练与验证关系。** 官方 2,699 条文本按本项目独立的 GroupKFold 分成五折，各折 30 个 prompt，行数为 540、540、540、540、539。该映射由本项目保存，全部模型 ID 与 prompt ID 仅用于关联、分组和评估，模型输入使用正文。[分折定义](../data/q8/prompt_folds.json)

baseline/mix20 与 centered off/on 构成四格，每格的外部阶段各产生一个起点，五个官方折从该起点独立适配并保持相同辅助策略。matched 的外部权重依赖官方训练折，因此每折分别建立外部阶段，再适配同一折。两阶段重新建立优化器。部分训练会记录实际预算，其日程和辅助损失系数按该预算定义；活跃 epoch 若没有全部类别的辅助支持，则不能定义 18 类均衡。

默认精度在支持的加速设备上采用 BF16，CPU 使用 FP32。FP16 的梯度缩放溢出重试同一窗口并恢复随机状态，只有成功更新才推进学习率与样本曝光。前向非有限值和无法恢复的梯度会终止该次训练，使不同方法的有效更新量保持可解释。

公开池上游曾使用官方文本或标签统计清理，因此这些官方五折衡量固定公共数据条件下的开发效果。更严格的泛化确认需要从筛选前数据按折重建，或使用所有相关成员均未见过的新 prompt。q8v5 full 权重已经使用过全部官方文本，重新切官方折不能消除其训练历史。[评估依据](../runs/q8v5_research_20261105/evaluation/analysis.md)

**概率与集成评价。** 当前同一次表示提取输出 plain 与 centered 原始分数，Gaussian 仅在同一 checkpoint 的官方训练侧表示上拟合。评价覆盖 plain、centered 活跃行与 singleton 回退、两头固定融合、三分支融合及 Gaussian 无排斥敏感性；各稀疏 cohort 独立按正文恢复组后重算关系分数。默认分组 TF-IDF 只在当前训练折拟合一次；原公开 query-transductive 拟合保留为显式对照，两种口径分开记录与汇总。报告整体与逐类 BA、长度和组大小、配对救回与损失、NLL、类均衡 NLL 和 Brier，五折逐行合并后计分。原有根目录预测保持 full/plain 兼容；未获有效训练的 centered 头不进入融合。[当前评价方法与实测](q8-evaluation.md)

现有公开模型的 2,699 条真实预测可复算得到 Stage 1 BA 0.48453、Stage 2 OOF BA 0.55937，救回 411 条、损失 209 条。这些历史预测用于本轮概率分析，新 q8 的训练收益仍待测量。[历史预测比较](../runs/q8_local_20261105/probability_analysis/20261105T080225Z_probability_comparison_dfa63a/comparison.json)

正式 0.668 中，q8 plain、centered、Gaussian 三个分支权重为 2、0.70、0.44。当前重放实现逐分支 beta=0、0.25、1 插值，并固定同一 cohort 旧系统的分支分母 M，再重新执行 comp、ATLAS 触发、软边际和尾部 gate。独立 q8 块诊断固定除以 2，不能当作全系统 M。现有正式 comp/ATLAS 等缓存不齐，只能明确报告可计算前缀；完整收益还需要合法的全系统预测、各成员未见的确认数据和实际时间预算。[分支定义依据](../runs/q8v5_research_20261105/evaluation/analysis.md) · [当前集成重放与缺失边界](q8-evaluation.md)

研究顺序为 baseline/mix20 × centered off/on 的同预算四格比较，并用相同辅助总强度的 global/class 两种归一化区分类别重平衡作用，再考察 matched 对短文本和薄弱类别的影响。每个方向都需检查新模型能否补充现有强成员的错误。LoRA+、额外对比目标与更多训练轮数保留为后续候选。[辅助监督与交互设计](centered-supervision.md) · [数据实验的正负依据](../runs/q8v5_research_20261105/experiments/selection.md)

**题目风险隔离的修复。** 隔离前，原池仅检查官方正文重复，官方 prompt 标记及风险 canonical 的排除只作用于新版。旧 baseline 因此保留了 38 条疑似官方题目再生成文本，涉及 9 个官方 prompt；旧 mix20 保留其中 23 条、涉及 5 个 prompt，两组均跨越五个验证折。37 条能从旧键直接识别：33 条带有 `pukkei37:pv:tr_pNNN`，另 4 条为 `bingli283:p015`。第 38 条旧键是无题意的 `nogrp:2cd6756e5045`，必须通过相同规范化正文关联新版的 `bingli283/...:p147`；先清理新版会丢失这条证据。

正文证据支持同题或近题的疑点：仅在官方正文拟合的 word unigram/bigram TF-IDF 中，38 条的标记 prompt 有 35 条平均余弦相似度排名第一，38 条均在前三。但两份原始池都没有生成 prompt 全文，不能断言逐字同题，也不能据此量化分数虚高。相似度只作为诊断，未被用作追加删除的阈值。[原始逐行证据](../runs/q8_audit_20261105/data/potential_prompt_overlap.csv) · [题目关联分析](../runs/q8_audit_20261105/data/potential_prompt_overlap_summary.json)

当前规则先在两份原始池联合发现官方正文重复、完整官方 prompt 编号、跨标签正文冲突及已有风险标志，再沿规范化正文、有效 canonical、无歧义完整题目键传播，直到没有新增风险。保留完整题目键的命名空间，不按编号后缀合并；旧键实际跨聚合来源复用，因此也不按来源拆断。空键、占位符和尾部空后缀不传播；与多个原始 canonical 关联的键不传播，避免把整份文件误当同题组。新版存在单个文件级组包含 7,521 行、2,913 个 canonical 的实例，歧义限制有实际必要。

独立核对与实现的逐行排除集合一致：旧池 37 条直接种子经正文关联扩展至 38 条；新版 86 条直接编号命中经 canonical 扩展至 95 条，随后闭包不再扩大。新版额外 9 条来自 `trnhip` 的 `own_bank`，与 `bingli283:p104` 的 `centroid` 共用 canonical，属于继承关联风险，不能当作已证实同题。最终两组均无这 38 条或其规则可关联风险的残留；matched 使用同一清理后 baseline。原始输入、官方正文、标签顺序和五折映射保持不变。[联合隔离结果](../runs/q8_isolation_20261105/isolation.json) · [逐行隔离原因](../runs/q8_isolation_20261105/isolated_rows.csv) · [独立原始池审计](../runs/q8_isolation_20261105/evidence/raw_quarantine_summary.json)

本次重建是新的数据条件。baseline 恰好减少 38 条；mix20 在清理后重新计算全部 72 格配额并重选，同旧 mix20 保留 103,389 条、移出 16,510 条、移入 16,472 条。移出包括 23 条风险、16,482 条旧池重选文本和 5 条新版配额缩减文本，移入全部来自旧池。组优先级随机排列随候选组数量改变，因此不能把修复前后的差异归因于只删除 23 条。新增文本始终相对于原始旧池定义，已排除文本不能从新版回流。后续 baseline/mix20 比较应共同使用这一修复后的数据条件；隔离本身不构成提分证据，也未消除公共池上游使用官方统计的历史影响。[前后数据与采样比较](../runs/q8_isolation_20261105/analysis.json)

**辅助监督不均衡的修复。** 保留的 native 参照显示，整体 centered 覆盖相近仍掩盖了类别差异。隔离后数据采用原两轮采样时：

| 类别 | baseline centered 覆盖 | mix20 centered 覆盖 |
|---|---:|---:|
| Fable | 77.09% | 76.23% |
| Gemini 3.7 Flash | 89.04% | 86.36% |
| Kimi K3 | 96.58% | 91.51% |
| GPT 6 Astra | 97.78% | 97.80% |

Gemini 3.7 的二行 centered 曝光占比还从 4.87% 升至 16.02%。原全局类别权重只平衡 plain 总质量，因此旧两池比较同时改变了文本、同伴和组大小。新方案固定每轮 28,165 个共同三行组，分别校准 centered 的 18 类损失系数；两池辅助正文、同伴、窗口和逐行系数已完全一致。原生 Fable/Astra 的结构性伙伴供给仍不同，新方案首轮物理覆盖分别为 59.91% / 74.80%，没有凭空补齐同题信息，但各目标类别的辅助预算均为 `6659/18`。关闭 centered 保持同样布局，四格分别衡量数据、辅助作用及交互；global_mass 对照保持总强度相同，以免把整体放大误认为类别重平衡。当前结果限于真实数据和损失计划，不构成提分证据。[修复方法与边界](centered-supervision.md) · [独立核验](../runs/q8_centered_20261105/final_plan_verification.json)

关系评价现在覆盖 full、每题一条、1–3 条、1–6 条及类别不均衡集合，每个集合单独恢复簇。当前训练为三行组，推断仍可能形成二至十八行簇。此前 seed42 分组诊断中，每题 1–3 条的 310 行里有 13 行位于混合 prompt 簇；每题一条时各折仅 30 行，原 TF-IDF 参数触发 singleton 回退。新评价保留这些诊断，并进一步计算真实分支预测，仍不能假设隐藏测试会遵循任一固定组大小。[历史分组诊断](../runs/q8_audit_20261105/eval/group_diagnostics.json) · [新增稀疏分支评价](q8-evaluation.md)

组大小本身还改变中心化尺度。在固定的 18 条表示中，给定一条回答并均匀选择其余 `m−1` 条同伴，有 `E[z_i−mean_subset] = 18(m−1)/(17m) × (z_i−mean_full)`；三行和二行组的系数分别为 12/17 与 9/17。实际采样并不完全均匀，这一解析结果不能代替模型实验。历史 query-transductive 口径下，真实 CPU TF-IDF/SVD 双头 OOF 的 plain/two-head/three-branch BA 为 0.25522/0.29448/0.29856，但 Gaussian 在一个稀疏集合中降分；在同一 310 行稀疏集合上，改为默认训练折拟合后，关系活跃行从 268 降至 199，三分支 BA 从 0.30422 降至 0.29230；full 三分支则升至 0.30375。这说明布局与分组协议都需要分列，仍不是 Qwen 或正式 0.668 的提分证据。[真实 CPU 研究](q8-evaluation.md)

新辅助权重已经接入训练反传；当前独立实测覆盖真实数据、采样和窗口后的损失系数，尚不能代替 Qwen 模型前向、反向、数值稳定性与提分实验；两阶段接续还要求保持同一底座权重及 tokenizer，目前配置哈希只验证架构配置，无法证明这两者相同。
