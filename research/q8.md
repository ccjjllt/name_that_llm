# Name That LLM：Q8 研究

## 研究问题与评价方法

当前只回答三件事：新增外部文本是否有效；centered 辅助的类别分配是否合理；P/C/G 概率尺度和融合权重是否适配。模型结构与训练条件固定，逐项识别。

官方 2,699 条、150 prompt、18 类；Fable 149 条余类各 150 条。主指标 BA（类别召回均值），按 prompt 留出。正文为输入，ID 只做关联。保留大小写标点排版，需拟合变换只用训练侧。

不假设隐藏测试类等量或同题覆盖全类。除完整集，另评每题 1 条、1–3 条、1–6 条及不均衡集；每集重建文本关系，不裁切复用。真实 prompt 不参与推断聚类，缺关系回退 plain，词表/IDF 训练侧拟合。

融合用固定内外层：每折 30 prompt 外层，其余 96 训练 + 24 内层开发；模型、Gaussian、变换只拟训练侧，温度与权重只在开发集定，之后用于外层。该训练集小于早期 120 训练 prompt 的 Q8 五折，绝对分数不可比。

公共外部池经过使用官方文本/统计量的上游筛选，官方 prompt 留出不能消除该历史。当前为固定公共来源下的开发比较，需新 prompt 或按折重建筛选才算更强泛化。

## 外部数据与来源协议

统一条件下 baseline 119,616 条，等配额 mix20 119,616 条（23,372 新于 baseline），expanded 238,353 条（118,737 新于 baseline）。来源为 Open Pool v15、Extended v8、exact-route v2。“新增”指相对训练参照，不等于新生成。[统计](../data/q8_scale/manifest.json)

全池规模≠实际训练量：已完成比较实际曝光 baseline 35,997、expanded 36,000（仅 18,018 新于 baseline）；centered 文本 31,611→24,255（−23.3%），Kimi 1,782→1,045。加权不能补回丢失文本/伙伴，故该实验不能分离数据多样性与监督变化。

已知官方再生成、标签冲突、身份不匹配、未完成响应已按证据排除。弱 prompt 证据文本只用于 plain；旧分组证据不因此升级。正文与导入源一致只证本项目未改写，不证上游未合段/重写。

生成协议证据分布：`protocol_unknown` 206,021；可关联请求日志 10,193；有来源协议说明 11,352；逐行明确合段/改写 3,711；仅来源报告空白规范化 7,076。明确变换中 3,617 合段、94 二轮改写。模型/ prompt/设置/变换/上游筛选为独立证据维，同题可靠≠模型版本与完整请求可靠。

治理口径：扩展池 214,353/238,353（89.93%）只有来源标签；`request_and_return_recorded` 仅为导出记录≠独立验证权重版本；`model_version` 仅 1,128 条且全为类别名，另有 2,075 条日期返回标识、300 条非空 system_fingerprint，均只作标识/指纹。[字段审查](../runs/provenance_followup_20261107/local_audit/model_field_audit.json)

`protocol_unknown` 206,021/238,353（86.44%）为设置+变换复合分类，其中生成状态未知 126,080、已有部分说明 79,802+139；真正 `generation_status=unknown` 占 52.90%，不可写成“86.44% 全无信息”。治理保留各维证据，只用正文逐字相同+标签身份一致记录补逐行证据；未知态保留，不判错标/低质/删除，已知冲突与正文重合隔离不放宽。

来源历史区分 prompt 设计、长度目标、输出筛选、身份先导与容器筛选史：Trnhip 依赖官方；Extended/exact-route 用过官方类长；Elliot 非 pass 文件只能撤销后段筛选；Kilupy 3,338 prompt 可按公开构造代码复现字段，但不证历史选择独立，且 model 字段允许回退请求别名。[登记](../runs/provenance_followup_20261107/upstream/source_history_registry.json) 当前 OOF/曲线/校准均按固定公共来源开发比较解释；分组隔离、无正文重合、不用筛选分数作特征，均不消除上游依赖。

敏感性检查（同 prompt 五折 TF-IDF 线性：官方单独/加当前 Kilupy/加原始 Kilupy）：原始与当前差异区间含零，无删除依据；数量组成同变且题目已被观察，既非归因也非独立验证/Q8 成绩。[设计与结果](../runs/provenance_followup_20261107/upstream/cpu_source_sensitivity/summary.json)

逐行证据修正文件名推断：扩容 Elliot 1,979 条实为 1,376 host + 568 host_join + 12 mt2 + 23 calm，不可按名判合段；未知协议≠错标/低质，不因降分删来源。尚无同响应变换前后配对，同 prompt 他条回答不能充原文；来源替换只估“来源+协议组合”效果。[证据分析](../runs/protocol_repair_20261106/sources/independent_condition_review.json)

## 辅助目标的类别分配与阶段参照

设活跃前缀辅助总系数 S、c 类为 S_c、更新 U：global_mass 全行乘 U/S 保原份额；class_mass 对 c 类乘 U/(18S_c) 使每类累计 U/18。λ 相同、总强度相同，但梯度/伙伴/信息量不同；缺支持的类不可靠放大权重定义均衡。

比较只改外部归一化：两臂同文本/伙伴/窗口/初值，官方固定 class_mass 再各适配；同折训练文本/关系/系数/LR/预算一致。两阶段同改则只记整体策略差。

CPU 小模型（3,600 外部正文 TF-IDF+SVD32+低秩双头；外部单池三元组 200 步，官方每组两轮 192 步；87 独有 prompt、120 prompt 次，组间宏平均非 pooled）：外部 class vs global，plain −0.046pp，centered +0.278pp（区间 [−0.227,+0.766]），P+C −0.231pp（仅 5 文 5 题）。无 class 一致优势，不替 Qwen 选政策。两臂各 3,204 关系正文，Fable 覆盖 152/210=72.38%，Astra 214/230=93.04%；裁剪频繁但裁剪系数≠有效 LR，阈值仍 1。[结果](../runs/auxiliary_adaptation_20261106/weighting/summary.json)

供给层次（扩展池首轮）：全池 238,353；可构造关系且 prompt 非空 184,312；有异类伙伴 180,044；当前三元组覆盖 159,888；保尾批候选 174,978；允许二元组组合上限 180,014。当前三元组已达不重复上限，改进装箱不增覆盖；原采样器 7,545 两条尾批退 plain（15,090 行可单列研究）；允许二元会改几何/梯度/批次/窗口，覆盖增≠效果增，不可混入 class/global 比较。58,309 行无资格/无伙伴，30 行受同题数限，不可加权修复；两轮共覆盖 170,846 独有正文（71.68%），类对相遇 550–6,222（11.31 倍）。[供给](../runs/centered_reference_20261107/information/summary.json)

阶段二乘二（同扩展池与内层协议，关断经 λ=0 实现，保分支计算与 dropout 随机数消费）：off_off（外关官关）、off_on、on_off、on_on（class_mass）；另保 global_on 只比外部权重。外部共用初值，同外部终点共用官方起点；同条件固定文本/伙伴/顺序/批次/两轮日程与每折 96 fit prompt。主读出 plain 五折 OOF，联合 on_on−off_off，另报四条件差与交互 on_on−on_off−off_on+off_off；off_off 的 C 未训练，其回退分非独立 C 成绩。保 18 类竞争与类长诊断，区间按 prompt 配对，不升级独立泛化。

同设计 CPU 短前缀（复用 baseline 3,600 拟合 TF-IDF/SVD32 与初值，改 expanded，只跑完整 26,484 步前 200 步，官方 96 fit prompt 两轮 192 步）：off_off 7.8171%、off_on 7.7427%、on_off 7.8171%、on_on 7.7427%、global_on 7.7427%；on_on−off_off −0.0743pp，区间 [−0.2230,+0.0741]。模型确变但弱替代+暖启动前段不足以定 Qwen 取舍；同硬预测/零宽区间≠等效。前 200 步 class/global 总系数约 207.667/207.877（非重归一 200），短前缀不沿用“等累计强度”表述。[训练与限制](../runs/centered_reference_20261107/cpu/summary.json)

## 内层概率校准与融合
