# Name That LLM：Q8 研究

## 研究问题与评价方法

当前研究聚焦三个问题：新增外部文本是否提供有效信息；centered 辅助监督的类别分配是否合理；plain、centered 与 Gaussian 的概率尺度和融合权重是否适配当前模型。先固定模型结构与训练条件，分别识别这些因素的作用。

官方训练集有 2,699 条文本、150 个 prompt、18 个类别；Fable 为 149 条，其余各 150 条。主指标 balanced accuracy（BA）是各类别召回率的平均值。按 prompt 留出，正文是分类输入，ID 和 prompt ID 仅用于关联与评估。保留大小写、标点和排版，所有需拟合的变换只使用相应训练部分。

不假设隐藏测试类别等量，也不假设同题回答包含全部类别或每类至多一次。除完整集合外，分别评价每题一条、每题 1–3 条、1–6 条及类别不均衡集合；每个集合重新恢复文本关系，不能简单裁切完整集合的关系分数。真实 prompt 不参与推断聚类。默认分组词表与 IDF 在训练侧拟合，关系不可用时回退 plain。

融合研究采用固定内外层划分：每折 30 个 prompt 作外层评价，其余分成 96 个训练 prompt 和 24 个内层开发 prompt。模型、Gaussian 统计量及分组变换只拟合训练部分；温度与融合权重只在开发集确定，之后应用于外层。该训练集比早期使用 120 个训练 prompt 的 Q8 五折更小，二者绝对分数不能直接比较。

公共外部池曾经过使用官方文本或统计量的上游筛选。官方 prompt 留出不能消除这段历史，当前结果属于固定公共数据条件下的开发研究。更强的泛化确认需要新的 prompt 或按折重建上游筛选。

## 外部数据与来源协议

统一数据条件下，baseline 有 119,616 条文本，等类别×长度配额的 mix20 也是 119,616 条，其中 23,372 条新于 baseline；expanded 有 238,353 条，其中 118,737 条新于 baseline。来源包括 Open Pool v15、Extended v8 与 exact-route v2。“新增”指相对训练参照新增，不等于近期生成。[数据统计](../data/q8_scale/manifest.json)

全池规模不等于实际训练量。已完成 Q8 比较中，baseline 实际曝光 35,997 条，expanded 为 36,000 条；后者只有 18,018 条新于 baseline。扩容同时改变了关系供给：centered 文本从 31,611 减至 24,255，下降 23.3%，Kimi 从 1,782 减至 1,045。提高剩余样本的损失权重不能恢复丢失的文本和伙伴，因此该实验不能将数据多样性与辅助监督变化分别归因。

已知官方题目再生成、标签冲突、身份不匹配与未完成响应按关联证据共同排除。新增的弱 prompt 证据文本只用于 plain；旧参照的历史分组证据不能因此被视为同等可靠。正文与导入源一致只说明本项目没有改写，不能证明上游没有合段或重写。

扩大池的生成协议证据分布为：

| 条件 | 文本数 |
|---|---:|
| 协议组合证据不足（`protocol_unknown`） | 206,021 |
| 可关联请求日志 | 10,193 |
| 有来源协议说明 | 11,352 |
| 逐行明确合段或改写 | 3,711 |
| 仅来源报告空白规范化 | 7,076 |

明确变换中有 3,617 条合段、94 条二轮改写。模型身份、prompt 身份、生成设置、文本变换和上游筛选是不同证据维度；同题关联可靠不代表模型版本或完整请求已确认。来源说明也不等于本项目亲自观察的 API 调用。

### 现有数据的治理口径

扩展池的 214,353／238,353 条（89.93%）只有来源标签。`request_and_return_recorded` 表示来源导出中记录了请求与返回标识，不等于本项目独立确认了提供方实际权重版本。可精确关联的 `model_version` 字段仅覆盖 1,128 条，值全部是类别别名；另有 2,075 条日期样式返回标识和 300 条非空 `system_fingerprint`。这些分别保留为标识或指纹证据，均不能自动升级为不可变版本已验证。[模型字段审查](../runs/provenance_followup_20261107/local_audit/model_field_audit.json)

206,021／238,353 条（86.44%）的 `protocol_unknown` 是生成设置与文本变换共同决定的复合分类。其中 126,080 条生成状态本身未知，79,802 条已有来源级部分说明，139 条已有逐行 setting 与来源说明；后两组仍可能缺乏完整调用或变换证据。真正 `generation_status=unknown` 占全池 52.90%，不能把 86.44% 写成“完全没有生成信息”。

治理将身份标识、版本字段、生成设置、变换以及来源历史分别保留，并只用正文逐字相同、标签和文本身份一致的记录补充逐行证据。规范化后相似的文本只能留下变体引用，不能互借调用证据。未知状态保留在研究数据中，不自动解释为错标、低质量或删除理由；当前已知冲突、官方正文重合等隔离政策不因此放宽。

来源历史进一步区分 prompt 设计、长度目标、输出筛选和身份先导实验，并与聚合容器的筛选历史分开。Trnhip 的 prompt-topic 筛选及身份先导实验依赖官方数据；Extended、exact-route 等使用过官方类别长度；Elliot 的现有非 pass 文件也已经过前三步筛选，只能撤销后续 discriminator 筛选，不能恢复之前删除的回答。Kilupy 的 3,338 个 prompt 可由所发布的固定构造代码逐字段复现，代码不读取官方文件，但这不能证明全部历史设计选择独立，且其 model 字段允许回退为请求别名。[来源历史登记](../runs/provenance_followup_20261107/upstream/source_history_registry.json)

当前公共池训练的 OOF、学习曲线与内层校准结果均按“固定公共来源条件下的开发比较”解释。分组隔离、无直接正文重合和不把筛选分数用作特征，都不能消除上游已经发生的官方依赖。治理记录限定证据与结论的使用范围，不把现有 CV 改称新的独立泛化确认。

作为治理敏感性检查，在相同官方 prompt 五折上比较了固定 TF-IDF 线性模型的官方数据单独训练、加入当前 Kilupy 子集、加入原始 Kilupy 导出三种条件。每类总损失权重相同，新增来源只覆盖五个类别；原始导出与当前子集的差异区间包含零，没有提供按这一结果删除来源的依据。两种外部数据同时改变数量与组成，且官方题目此前已被研究观察，因此该检查既不能归因某项上游筛选，也不是独立验证或 Q8 成绩。[预声明设计与结果](../runs/provenance_followup_20261107/upstream/cpu_source_sensitivity/summary.json)

逐行证据修正了此前按文件名推断的错误：扩容曝光中 Elliot 的 1,979 条实际为 1,376 条 host、568 条 host_join、12 条 mt2 和 23 条 calm，不能把名称含 join 的文件桶全部判为合段。未知协议也不等于错标或低质量，不能仅因相关类别降分就删除该来源。

目前没有可证明的历史同响应变换前后配对。同 prompt 的另一条回答不能充当原文；不同响应之间的来源替换只能估计“来源与协议组合的效果”，不能单独归因于 reasoning、服务商或合段操作。[来源证据分析](../runs/protocol_repair_20261106/sources/independent_condition_review.json)

## 有限预算内的曝光与关系控制

### 前缀配额

全池类别×长度数量相同，不保证有限训练前缀相同。按 18 类、4 个长度桶比较前 2,000 次更新：

| 数据条件 | 原共享三元组方案的不等格数 | 最大格差 | 分层 plain 槽后的不等格数 |
|---|---:|---:|---:|
| 原数据池 | 69/72 | 44 | 0/72 |
| 更新数据池 | 71/72 | 41 | 0/72 |

当前方法保持共同关系三元组、伙伴顺序和窗口位置，按固定类别与长度顺序耦合剩余 plain 槽。两轮中每个对应槽的类别与长度均一致，因此任意共同前缀也一致。更新数据的前 2,000 步每臂为 35,997 条文本，其中 25,365 条参与共同关系监督；配平没有增加关系支持。

153 个无向类别对都出现过，但各对相遇次数为 50–537，覆盖仍不均匀。Fable 只有 1,175 条关系文本，GLM 5.3 为 1,703，GLM Flash 为 2,040，Kimi 为 1,428。研究同时看独有文本、prompt、伙伴文本与类别对频率，不以损失系数均衡代替信息量均衡。[前缀与伙伴覆盖](../runs/auxiliary_adaptation_20261106/sampling/prefix_and_partner_analysis.json)

### 固定关系的四类局部文本替换

该实验保留 baseline 的全部关系文本与伙伴，只在相同类别、长度的 plain-only 槽替换正文。早期独立准备的 2,000 步对照每臂有 35,997 条正文、31,611 条关系文本，908 条变化全部在 plain-only 槽。当前完整两轮数据和日程的前 2,000 步则有 905 条变化；两种构造预算不同，不能把旧的 908 条直接沿用。它们也与上述只取跨池共同关系的设计不同，不能混用分数或关系覆盖量。

当前每臂 119,616 条中有 2,955 条正文变化（2.4704%）。其中 2,948 条旧文本为 `protocol_unknown`，占被替换旧文本的 99.7631%，仅 7 条为 `protocol_documented`；新文本均为 `protocol_unknown`。这不是“可靠协议优于未知协议”的识别设计。复合分类相同也不代表证据各维度相同：替换前后生成信息和返回标识的覆盖发生了变化。2,925 条同时更换了记录来源，另 30 条是同来源的不同正文。[实际替换范围](../data/q8_source_full/historical_anchor_vs_protocol_unknown/intervention_scope/summary.json)

| 直接替换覆盖类 | 变化正文／该类总数 | 类内替换率 |
|---|---:|---:|
| Fable | 1,432／6,700 | 21.37% |
| GLM 5.3 | 634／8,026 | 7.90% |
| GLM Flash | 689／9,449 | 7.29% |
| Kimi | 200／6,574 | 3.04% |

估计对象是在既定模型、关系、类别和长度槽、总日程下，这批正文及其来源与证据结构联合变化的效果。18 类总体 BA 仍是任务层面的主结果，同时报告直接替换四类及未直接替换十四类。所有分组均保留 18 维类别竞争，只按真实标签筛评价行；十四类也可能因共享参数与推断关系改变，不能作为独立未处理对照。该局部处理不能外推为全部类别都接受同种替换的效果，也不能把总体增益除以 2.47% 当作每条替换的因果收益。分组结果不参与新增调参或改变内层融合选择目标。

上述早期 2,000 步对照的真实 tokenizer 计量中，两臂输入分别为 5,294,721 与 5,293,739 token，截断 3 与 2 条；关系输入的 token 量相同。这不是当前完整日程的前缀计量。相同文本数、词数桶和更新数仍不保证完全相同的计算量。[输入规模分析](../runs/exposure_contract_20261106/tokenization/pair_measurements.json)

## 辅助目标的类别分配

对每个活跃 epoch 的实际预算前缀，设辅助基础总系数为 S，各类为 S_c，更新数为 U。global_mass 对所有辅助行统一乘 U/S，保持原类别份额；class_mass 对类别 c 乘 U/(18S_c)，使每类累计系数为 U/18。两者 λ 相同、总强度相同，但梯度、伙伴供给和有效信息量不相同。缺少某类辅助支持时，不能靠无限放大权重定义该类均衡。

比较只改变外部阶段的归一化方式。两臂使用相同实际文本、伙伴、窗口和初始参数；官方阶段均固定 class_mass，再从各自外部终点适配。同一官方折的训练文本、关系、系数、学习率与更新预算保持一致。若两个阶段一起改变，结果只能解释为两阶段整体策略差异。

本地小模型研究使用 3,600 条实际外部正文拟合 token TF-IDF 与 32 维 SVD，再训练低秩投影、LayerNorm 和双头。外部采用单池三元组、200 更新，官方每组两轮、192 更新。它与计划中的共享三元组、2,000 更新 Q8 研究条件不同。

五组开发集有 87 个独有 prompt、120 次 prompt 出现，因此下表是组间 BA 宏平均，不是 pooled OOF：

| 官方适配后视图 | 外部 class_mass | 外部 global_mass | 差值（百分点） |
|---|---:|---:|---:|
| plain | 0.11115 | 0.11161 | −0.046 |
| centered，缺关系回退 plain | 0.12832 | 0.12554 | +0.278 |
| 固定 P+.35C | 0.10974 | 0.11206 | −0.231 |

centered 差异的条件化 prompt 配对区间为 [−0.227,+0.766] 个百分点；固定 P+C 的下降只涉及 5 条文本、5 个 prompt。该研究没有显示 class_mass 的一致优势，不能据此替 Qwen 选择归一化政策。[辅助权重研究结果](../runs/auxiliary_adaptation_20261106/weighting/summary.json)

两臂都只有 3,204 条关系正文。Fable 物理覆盖为 152/210=72.38%，Astra 为 214/230=93.04%；改变权重后仍然如此。共享参数的目标梯度方向会随训练变化，少数窗口没有给出持续压制主目标的证据。已有 Q8 更新与该 CPU 研究均频繁触发裁剪，但裁剪系数不是 Adam 的有效学习率，当前保留阈值 1。

### 信息供给与关闭辅助训练的参照

扩展池首轮各类别的实际三元组覆盖为 47.95%–91.56%，分母是各类全部训练正文。损失系数配平只改变已有关系行的强度，既不能增加独有正文，也不能补出不存在的同题异类伙伴。以下为同一冻结首轮计划的逐层分解：

| 供给层次 | 正文数 |
|---|---:|
| 扩展池全部正文 | 238,353 |
| 元数据允许构造关系且 prompt 非空 | 184,312 |
| 在该池中实际有同题异类伙伴 | 180,044 |
| 当前三元组实际覆盖 | 159,888 |
| 保留原采样器两条尾批后的候选覆盖 | 174,978 |
| 允许重新组合二元组与三元组的组合上限 | 180,014 |

当前三元组数已经达到该池在不重复正文条件下的三元组组合上限；单纯改进三元组装箱不能增加总覆盖。包装函数会把原采样器的 7,545 个两条尾批退回 plain，因此存在 15,090 条可以单独研究的供给损失。允许二元组后，均值消除的几何、梯度、物理批次和更新窗口也会改变；覆盖增加本身不证明预测效果增加，不能把这种改动悄悄混入 class/global 权重比较。58,309 条当前没有可用关系资格或异类伙伴，另 30 条受同题伙伴数量限制，不能靠加权修复。现有两轮共覆盖 170,846 条独有正文（71.68%）；153 个类别对均出现，但相遇次数仍为 550–6,222，相差 11.31 倍。[实际供给、伙伴频率与组合上限](../runs/centered_reference_20261107/information/summary.json)

为区分“如何分配辅助权重”和“是否需要辅助训练”，在相同扩展池与官方内层协议上声明阶段二乘二参照：

| 条件 | 外部 centered | 官方 centered |
|---|---|---|
| off_off | 关闭 | 关闭 |
| off_on | 关闭 | class_mass |
| on_off | class_mass | 关闭 |
| on_on | class_mass | class_mass |

原 global_mass 外部、class_mass 官方条件另行保留，只用于外部权重分配比较。外部共用实际初始参数，官方同一外部状态共用对应终点；各条件固定文本、伙伴、顺序、物理批次、两轮总日程和官方每折 96 个 fit prompt。关闭通过阶段 λ=0 实现，保留相同分支计算及 dropout 随机数消费。物理计划里的关系行不再等同于实际获得非零辅助监督的行。

### 分组误差与类别排斥的冲突

实现中的排斥有两种机制：大小不超过 3 的组使用禁止重复类别组合的精确联合模型；更大组使用软排斥项。最终输出是逐行边缘概率的 argmax，不能把它描述成最终类别严格唯一。主融合保留无排斥 G，含排斥 G 作为敏感性分析；真实 prompt 和标签只在完成推断后用于诊断，不用于拆组、过滤或切换分支。

在原 seed 42 的 1–3 条稀疏场景中，两个不同 prompt 的 Qwen 文本被误合。无排斥模型给这对真实同类组合的联合概率约为 0.01239，硬排斥将其置零，说明真实组合与假设冲突。不过，两种模型在这两行上的最终预测相同，排斥仅令平均 NLL 恶化约 0.02890。该场景总体 −1.6068 个百分点的 BA 差不能归因这对误合：纯同题关系组中，排斥相对无排斥救回 1 行、损失 6 行。

扩展到 10 个预声明 seed，每题 1–3 条时，排斥减无排斥 BA 差为 −1.6068～+1.1494 个百分点；每题 1–6 条时为 −1.2191～+1.0918。每题只留一条的场景也有 4/10 个 seed 出现不同 prompt 的误合，因此真实 singleton 布局不保证推断得到 singleton。新增报告将纯同题组、误合组、重复真实类组和硬／软排斥冲突分开，并保留完整 18 类竞争；不同分组上的分数差是条件化诊断，不是仅由分组质量造成的因果效果。[真实分组研究与逐例证据](../runs/fusion_robustness_20261107/grouping/summary.json)

### 多方向类别偏斜

旧不均衡场景的不同 seed 共用同一个类别保留率方向。新增研究预声明正向、反向及 18 个固定随机排列的循环移位，使每类在循环族中各经历一次全部保留率角色；每个方向分别使用 0.5–1.0 与 0.05–1.0 两档保留率、两个抽样 seed，共 80 个布局。每个子集重新从文本聚类、重新计算 C 和两种 G，不能截取 full cohort 的关系分数。模型、温度与各折选中配方全部冻结，不按布局调参。

| 选中融合减固定无排斥 G | 正差／负差布局数 | BA 差范围（百分点） |
|---|---:|---:|
| 温和偏斜 | 14／26 | −1.415～+0.767 |
| 严重偏斜 | 18／22 | −2.251～+2.923 |

五折合计 400 个子集中，53 个缺少一至两类，没有强行补齐；对应折内 BA 只描述出现的类别，不能叫完整 18 类 BA。每个布局合并五折后均有 18 类，方法只在同布局同一批行上配对比较。80 个布局相互重叠，只描述方向敏感性，不作为 80 个独立实验合并检验，也不是隐藏测试先验的估计。排斥 G 在严重偏斜的 4/40 个布局中低于无排斥 G，是否存在误合不能仅由差值符号判断。[多方向实测与固定输入记录](../runs/fusion_robustness_20261107/imbalance/summary.json)

逐组分解进一步发现，4 个排斥负 BA 布局中有 3 个完全没有误合；另一个严重反向布局的总差为 −0.4518 个百分点，纯组贡献 −0.3894、误合组贡献 −0.0624。四个布局的平均 NLL 反而都改善。因此，类别排斥假设确实会与错误分组冲突，但并不能把所有负 BA 差归因于误合，或把 BA 与概率质量的取舍混为一谈。[使用全布局分母的贡献分解](../runs/fusion_robustness_20261107/grouping/imbalance_conflicts.json)

## 尚待回答的研究问题

1. **类别均衡是否改善 Q8。** 在相同文本、伙伴、初值与总辅助强度下比较外部 class_mass/global_mass，官方适配固定；观察各分支、弱类与短文本，而非只比较单一融合分数。
2. **指定的四类局部文本替换是否有益。** 固定实际曝光和关系监督，报告总体、直接覆盖类与其他类的变化；目前不回答可靠协议与未知协议孰优。其他证据层级的对照需要独立的数据供给与实验定义，不能借用当前结果。
3. **2,000 更新是否足够。** 在预先指定的更新点和官方每轮结束观察固定内层开发集。总预算 2,000 的末步 LoRA LR 约 7.62e−11，而总预算 4,000 的第 2,000 步约 5.87e−5；辅助系数也会随总预算重新归一，因此两者不是同一个训练条件，不能仅按更新数比较。
4. **低自由度校准能否迁移到 Q8。** 保留四个独立分支、无排斥主方案和稀疏场景，按既定内层协议确定温度与权重，不在已观察的外层结果上反复扩大搜索。
5. **后端是否影响长期质量。** HF 与 Unsloth 需从相同实际可训练参数开始，使用相同输入与预算，同时比较开发质量、组件更新和耗时。短程吞吐或初始前向接近不足以证明长期等价。
6. **centered 本身是否值得保留。** 在固定供给下比较外部／官方阶段开关，以 plain 为主要读出，完整系统的合法融合另报；现有 CPU 短前缀结果不能决定 Q8 的取舍。
7. **扩大关系覆盖是否有益。** 二元尾批提供了明确的独立候选，但会改变监督几何与窗口；需要在单独计划中保留开启／关闭辅助的参照，不能从更多覆盖直接推断收益。
