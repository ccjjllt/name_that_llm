# Name That LLM：Q8 研究

## 研究问题与评价方法

当前研究聚焦三个问题：新增外部文本是否提供有效信息；centered 辅助监督的类别分配是否合理；plain、centered 与 Gaussian 的概率尺度和融合权重是否适配当前模型。先固定模型结构与训练条件，分别识别这些因素的作用。

官方训练集有 2,699 条文本、150 个 prompt、18 个类别；Fable 为 149 条，其余各 150 条。主指标 balanced accuracy（BA）是各类别召回率的平均值。按 prompt 留出，正文是分类输入，ID 和 prompt ID 仅用于关联与评估。保留大小写、标点和排版，所有需拟合的变换只使用相应训练部分。

不假设隐藏测试类别等量，也不假设同题回答包含全部类别或每类至多一次。除完整集合外，分别评价每题一条、每题 1–3 条、1–6 条及类别不均衡集合；每个集合重新恢复文本关系，不能简单裁切完整集合的关系分数。真实 prompt 不参与推断聚类。默认分组词表与 IDF 在训练侧拟合，关系不可用时回退 plain。

融合研究采用固定内外层划分：每折 30 个 prompt 作外层评价，其余分成 96 个训练 prompt 和 24 个内层开发 prompt。模型、Gaussian 统计量及分组变换只拟合训练部分；温度与融合权重只在开发集确定，之后应用于外层。该训练集比早期使用 120 个训练 prompt 的 Q8 五折更小，二者绝对分数不能直接比较。

公共外部池曾经过使用官方文本或统计量的上游筛选。官方 prompt 留出不能消除这段历史，当前结果属于固定公共数据条件下的开发研究。更强的泛化确认需要新的 prompt 或按折重建上游筛选。

## 模型与已取得的 Q8 结果

| 部分 | 固定方案 |
|---|---|
| 底座与表示 | Qwen3-8B-Base 前 24 层；第 2、4、6、8、12、16、20、24 层均值池化，各层 LayerNorm 后拼接 |
| LoRA | rank 16，alpha 32，dropout 0.05；注意力与 MLP 的七个投影 |
| 文本 | 最多 384 token，保留原文风格 |
| 目标 | 18 类 plain CE；可信同题三元组增加 centered CE |
| 优化 | AdamW，weight decay 0.01，10% warmup 后 cosine，head dropout 0.1，梯度裁剪 1 |
| 学习率 | 外部 LoRA/head：1e−4/1e−3；官方：5e−5/5e−4 |
| 阶段 | 外部阶段后接官方折内适配；两阶段分别建立优化器 |

centered 使用组内表示减去均值后的特征。plain 按训练集类别频率加权；辅助权重另行归一。结构依据公开 q8v5，外部学习率及部分优化细节为本项目研究选择。

已完成的 Q8 扩容比较使用相同外部 2,000 更新预算，再分别做官方五折、每折两轮。以下是本项目在同一 2,699 条官方文本上的 pooled OOF BA；Gaussian 独立视图及其无排斥版本是读取同一组预测后的事后诊断。

| 视图 | baseline | expanded |
|---|---:|---:|
| plain | 0.55566 | 0.57307 |
| centered，缺关系回退 plain | 0.63348 | 0.62682 |
| plain + centered | 0.60011 | 0.61531 |
| 固定三分支 P + .35C + .22G | 0.63013 | 0.63902 |
| Gaussian，缺关系回退 plain | 0.65757 | 0.65867 |
| 无类别排斥 Gaussian，缺关系回退 plain | 0.58940 | 0.59273 |

扩容使 plain 五折均改善，三分支却只有两折改善。三分支增量为 0.889 个百分点，按 prompt 配对重采样的描述性 95% 区间为 [−0.484,+2.259] 个百分点。GLM 5.3、GLM Flash、Kimi 的三分支召回分别下降 4.00、4.67、4.00 个百分点，Fable 下降 0.67 个百分点。部分稀疏集合也下降，平均收益没有覆盖所有类别与布局。[Q8 配对结果](../runs/scale_research_20261105/analysis_v2/result_summary.json)

固定融合低于 Gaussian 单分支，说明分支组合有改进空间；但 Gaussian 的优势明显依赖组内类别排斥假设。它不是经过独立选择的新成绩，也不足以支持直接改成 Gaussian-only。[分支诊断](../runs/deep_audit_20261106/evaluation/branch_diagnostics.json)

本项目公开集成复现的 Public LB 为 0.668。它是整套历史集成的成绩，与本表 Q8 单成员 OOF 不是同一评价对象，不能用上述变化推断排行榜增益。

## 外部数据与来源协议

统一数据条件下，baseline 有 119,616 条文本，等类别×长度配额的 mix20 也是 119,616 条，其中 23,372 条新于 baseline；expanded 有 238,353 条，其中 118,737 条新于 baseline。来源包括 Open Pool v15、Extended v8 与 exact-route v2。“新增”指相对训练参照新增，不等于近期生成。[数据统计](../data/q8_scale/manifest.json)

全池规模不等于实际训练量。已完成 Q8 比较中，baseline 实际曝光 35,997 条，expanded 为 36,000 条；后者只有 18,018 条新于 baseline。扩容同时改变了关系供给：centered 文本从 31,611 减至 24,255，下降 23.3%，Kimi 从 1,782 减至 1,045。提高剩余样本的损失权重不能恢复丢失的文本和伙伴，因此该实验不能将数据多样性与辅助监督变化分别归因。

已知官方题目再生成、标签冲突、身份不匹配与未完成响应按关联证据共同排除。新增的弱 prompt 证据文本只用于 plain；旧参照的历史分组证据不能因此被视为同等可靠。正文与导入源一致只说明本项目没有改写，不能证明上游没有合段或重写。

扩大池的生成协议证据分布为：

| 条件 | 文本数 |
|---|---:|
| 协议仍未知 | 206,021 |
| 可关联请求日志 | 10,193 |
| 有来源协议说明 | 11,352 |
| 逐行明确合段或改写 | 3,711 |
| 仅来源报告空白规范化 | 7,076 |

明确变换中有 3,617 条合段、94 条二轮改写。模型身份、prompt 身份、生成设置、文本变换和上游筛选是不同证据维度；同题关联可靠不代表模型版本或完整请求已确认。来源说明也不等于本项目亲自观察的 API 调用。

逐行证据修正了此前按文件名推断的错误：扩容曝光中 Elliot 的 1,979 条实际为 1,376 条 host、568 条 host_join、12 条 mt2 和 23 条 calm，不能把名称含 join 的文件桶全部判为合段。未知协议也不等于错标或低质量，不能仅因相关类别降分就删除该来源。

目前没有可证明的历史同响应变换前后配对。同 prompt 的另一条回答不能充当原文；不同响应之间的来源替换只能估计“来源与协议组合的效果”，不能单独归因于 reasoning、服务商或合段操作。[来源证据分析](../runs/protocol_repair_20261106/sources/independent_condition_review.json)

## 有限预算内的曝光与关系控制

### 前缀配额

全池类别×长度数量相同，不保证有限训练前缀相同。按 18 类、4 个长度桶比较前 2,000 次更新：

| 数据条件 | 原共享三元组方案的不等格数 | 最大格差 | 分层 plain 槽后的不等格数 |
|---|---:|---:|---:|
| 原数据池 | 69/72 | 44 | 0/72 |
| 更新数据池 | 71/72 | 41 | 0/72 |

当前方法保持共同关系三元组、伙伴顺序和窗口位置，按固定类别与长度顺序耦合剩余 plain 槽。两轮中每个对应槽的类别与长度均一致，因此任意共同前缀也一致。更新数据的前 2,000 步每臂为 35,997 条文本，其中 25,365 条参与共同关系监督；配平没有增加关系支持。

153 个无向类别对都出现过，但各对相遇次数为 50–537，覆盖仍不均匀。Fable 只有 1,175 条关系文本，GLM 5.3 为 1,703，GLM Flash 为 2,040，Kimi 为 1,428。研究同时看独有文本、prompt、伙伴文本与类别对频率，不以损失系数均衡代替信息量均衡。[前缀与伙伴覆盖](../runs/auxiliary_adaptation_20261106/sampling/prefix_and_partner_analysis.json)

### 来源替换

来源实验采用另一种固定关系设计：保留 baseline 的全部关系文本与伙伴，只在相同类别、长度的 plain-only 槽替换正文。当前一组对照前 2,000 步每臂有 35,997 条正文、31,611 条关系文本，908 条变化全部在 plain-only 槽。它与上述只取跨池共同关系的设计不同，不能混用分数或关系覆盖量。

真实 tokenizer 下，两臂实际输入分别为 5,294,721 与 5,293,739 token，截断 3 与 2 条；关系输入的 token 量相同。相同文本数、词数桶和更新数仍不保证完全相同的计算量。[输入规模分析](../runs/exposure_contract_20261106/tokenization/pair_measurements.json)

## 辅助目标的类别分配

对每个活跃 epoch 的实际预算前缀，设辅助基础总系数为 S，各类为 S_c，更新数为 U。global_mass 对所有辅助行统一乘 U/S，保持原类别份额；class_mass 对类别 c 乘 U/(18S_c)，使每类累计系数为 U/18。两者 λ 相同、总强度相同，但梯度、伙伴供给和有效信息量不相同。缺少某类辅助支持时，不能靠无限放大权重定义该类均衡。

比较只改变外部阶段的归一化方式。两臂使用相同实际文本、伙伴、窗口和初始参数；官方阶段均固定 class_mass，再从各自外部终点适配。同一官方折的训练文本、关系、系数、学习率与更新预算保持一致。若两个阶段一起改变，结果只能解释为两阶段整体策略差异。

本地小模型研究使用 3,600 条实际外部正文拟合 token TF-IDF 与 32 维 SVD，再训练低秩投影、LayerNorm 和双头。外部采用单池三元组、200 更新，官方每组两轮、192 更新。它与计划中的共享三元组、2,000 更新 Q8 研究条件不同。

五组开发集有 87 个独有 prompt、120 次 prompt 出现，因此下表是组间 BA 宏平均，不是 pooled OOF：

| 官方适配后视图 | 外部 class_mass | 外部 global_mass | 差值（百分点） |
|---|---:|---:|---:|
| plain | 0.11115 | 0.11161 | −0.046 |
| centered，缺关系回退 plain | 0.12832 | 0.12554 | +0.278 |
| 固定 P+.35C | 0.10974 | 0.11206 | −0.231 |

centered 差异的条件化 prompt 配对区间为 [−0.227,+0.766] 个百分点；固定 P+C 的下降只涉及 5 条文本、5 个 prompt。该研究没有显示 class_mass 的一致优势，不能据此替 Qwen 选择归一化政策。[辅助权重研究结果](../runs/auxiliary_adaptation_20261106/weighting/summary.json)

两臂都只有 3,204 条关系正文。Fable 物理覆盖为 152/210=72.38%，Astra 为 214/230=93.04%；改变权重后仍然如此。共享参数的目标梯度方向会随训练变化，少数窗口没有给出持续压制主目标的证据。已有 Q8 更新与该 CPU 研究均频繁触发裁剪，但裁剪系数不是 Adam 的有效学习率，当前保留阈值 1。

## 内层概率校准与融合

P、C、含排斥 G、无排斥 G 均作为独立分支。主融合使用无排斥 G，含排斥方案只作敏感性分析；无关系时使用同一个 plain 回退。不能把完整近等量面板上的排斥收益当作隐藏测试满足类别唯一性的证据。

每折先在完整内层开发集上分别拟合四个正标量温度，范围固定为 [0.05,20]，目标为 balanced NLL；关系分支只使用活跃行。冻结温度后，从原有 11 个非负候选中按开发 BA 选权重：P、C、G，以及 P+cC+gG，其中 c∈{0,.35,1}、g∈{0,.22,1}，去除重复 P。平分按固定顺序选择，不联合搜索温度、组大小、聚类阈值或布局专用权重。

以下研究使用相同的 CPU 内层训练模型：词／字符 TF-IDF、128 维 SVD 与双分类头，仅在各折 96 个训练 prompt 拟合。它与上一节 32 维可训练模型是两个独立实验。

| 独立分支 | 校准前后 BA | 原 balanced NLL | 校准后 balanced NLL |
|---|---:|---:|---:|
| P | 0.25150 | 2.26233 | 2.09110 |
| C，含 plain 回退 | 0.27597 | 2.41911 | 2.16361 |
| 含排斥 G，含回退 | 0.32265 | 2.06141 | 1.93548 |
| 无排斥 G，含回退 | 0.31080 | 2.11130 | 1.98009 |

P/C 的拟合温度约 1.75–1.95／1.73–2.12，两个 G 约 0.47–0.62／0.44–0.61。前者需要压平、后者需要锐化，说明继承的概率尺度不一致。正温度不改变单分支排序，因此单分支 BA 不变，概率质量则改善。

| 同一外层集合的融合 | BA | balanced NLL |
|---|---:|---:|
| 未校准的无排斥内层选择 | 0.29856 | 2.47950 |
| 校准后的无排斥内层选择 | 0.30448 | 2.03382 |
| 校准后的含排斥敏感性选择 | 0.32598 | 1.92499 |
| 固定无排斥 G，已校准 | 0.31080 | 1.98009 |

主融合 BA 增量为 0.00592，prompt 配对 95% 区间为 [−0.00333,+0.01519]，包含零，并且仍低于固定无排斥 G。校准改善了概率质量，没有证明有限开发集选权重能稳定胜过固定方案。

| 外层场景 | 未校准主融合 BA | 校准主融合 BA |
|---|---:|---:|
| 完整集合 | 0.29856 | 0.30448 |
| 每题一条 | 0.24152 | 0.24152 |
| 每题 1–3 条 | 0.28751 | 0.28682 |
| 每题 1–6 条 | 0.29541 | 0.30303 |
| 类别不等量 | 0.30559 | 0.30516 |

稀疏和不等量集合并未一致改善。24 个开发 prompt 同时用于温度拟合和候选选择，开发分数是乐观的拟合诊断。外层未参与本轮拟合，但此前研究已查看过这些数据；本轮是固定协议下的配对方法研究，不是新的独立确认。各区间也不涵盖训练 seed、划分与研究选择的不确定性。[校准与融合结果](../runs/auxiliary_adaptation_20261106/fusion/calibrated_cpu_v2/summary.json)

## 下一轮实验规模

下一轮保留模型结构、LoRA rank、优化器和官方适配配方，增加外部实际训练量。辅助权重对照使用现有扩展池的全部 238,353 条文本，每条训练两次：每臂 476,706 次曝光、26,484 次更新。两臂在同一个池内形成完全相同的三元组，只改变 class_mass/global_mass 的辅助系数分配；官方仍为各五折、每折 96 个训练 prompt、两轮 192 更新。

这与此前 baseline 的 35,997 条实际曝光不同：同时扩大了数据、预算并改变了伙伴供给，不能把未来与旧成绩的差异解释为单纯延长训练的效果。长日程中的第 2,000 步也不是原来的 2,000 步终点，学习率与辅助系数均按新总预算定义。

来源替换对照保持每臂 119,616 条及固定 baseline 关系，预算放大至完整两轮、每臂 239,232 次曝光和 13,292 次更新。只使用历史参照与协议未知新增这一对条件；不同正文仍只替换 plain-only 槽。两阶段分别使用既定配方，不将来源实验和辅助权重实验混为同一个消融。

来源对照共有 2,955 条独有正文变化，两轮出现 5,910 次，全部位于 plain-only 槽。完整训练规模如下；token 包括重复训练曝光，不含开发评价、梯度诊断和重试。

| 对照 | 每臂外部更新 | 官方每折更新 | 两臂含官方五折的总更新 | 总有效 token |
|---|---:|---:|---:|---:|
| 扩展池 class/global | 26,484 | 192 | 54,888 | 143,474,716 |
| 固定关系的来源替换 | 13,292 | 240 | 28,984 | 76,843,990 |

来源实验保留原来每折 120 个训练 prompt 的评价条件；辅助权重与融合研究则留出内层开发集，只训练 96 个 prompt。两个实验的绝对成绩不能作为相同训练范围下的直接比较。

以上是新实验设计，尚无相应的 Qwen 训练效果结果。

## 尚待回答的研究问题

1. **类别均衡是否改善 Q8。** 在相同文本、伙伴、初值与总辅助强度下比较外部 class_mass/global_mass，官方适配固定；观察各分支、弱类与短文本，而非只比较单一融合分数。
2. **来源变化是否提供有效信息。** 固定实际曝光和关系监督，仅替换 plain 文本；协议未知、请求日志明确与变换记录分别研究，避免把来源组合效应写成某项生成参数的因果作用。
3. **2,000 更新是否足够。** 在预先指定的更新点和官方每轮结束观察固定内层开发集。总预算 2,000 的末步 LoRA LR 约 7.62e−11，而总预算 4,000 的第 2,000 步约 5.87e−5；辅助系数也会随总预算重新归一，因此两者不是同一个训练条件，不能仅按更新数比较。
4. **低自由度校准能否迁移到 Q8。** 保留四个独立分支、无排斥主方案和稀疏场景，按既定内层协议确定温度与权重，不在已观察的外层结果上反复扩大搜索。
5. **后端是否影响长期质量。** HF 与 Unsloth 需从相同实际可训练参数开始，使用相同输入与预算，同时比较开发质量、组件更新和耗时。短程吞吐或初始前向接近不足以证明长期等价。
