# 实验方向

目标是尽快获得可信的对比和新的认识。这里记录研究假设，不设通过门槛，也不要求逐项完成；每次挑最有信息价值的一个变化去跑。

## 共同参照

- 使用 `prompt_id` 分组的交叉验证，固定切分和随机种子，主指标为 balanced accuracy。`prompt_id` 只用于分组，`id` 只用于关联结果。
- 保存 OOF 概率，观察每类 recall、混淆矩阵、文本长度分桶。先看具体错误，再决定新特征或新模型。
- 向量器等拟合只使用当前折训练数据。引入外部数据时记录来源、去重方式和切分变化。
- 不强制隐藏测试各类别等量，不默认每个 prompt 恰有 18 个回答。关系建模单独做实验，不能把训练布局当作已知测试条件。
- 正式比较用相同 5 折；快速探索可以少跑折数，但记录清楚，不能把不同口径分数混排。

## 1. 建立 TF-IDF 参照

**假设**：词汇、字符与排版能提供低成本的模型指纹。

- 先运行 `configs/tfidf.toml`，得到本项目自己的 OOF 分数和错误分布。
- 检查同厂商型号、短文本和低 recall 类别，选一两个最常见失败模式。
- 这份结果是后续实验参照；不设必须达到的分数，也不套用社区成绩。

## 2. n-gram 与风格特征

**假设**：对字符范围与文本节奏做少量调整，可以补充词级特征，尤其帮助短文本。

- 比较 `char` 与 `char_wb`、字符 n-gram 范围、LR 的 C 值；每次先改变一个主要变量。
- 加入引号、破折号、标点频率，句长与词长波动、换行、Markdown、词汇丰富度等简单特征。
- 保留大小写和原始标点。将“某模型不用某标点”当作可学习线索，而不是硬性标签规则。
- 看 OOF 误差是否改变、长度桶是否获益，而不只看总分的微小变化。

## 3. 冻结模型的多层表征

**假设**：浅层、中层与末层携带不同的风格信息，冻结编码器加轻量分类器能形成独立信号。

- 选择一个已有可用模型，比较几层 mean pooling，再尝试拼接；先小样本研究计算成本，再跑全量。
- 缓存文本表征，反复训练轻量分类器，避免每个实验重复编码。
- 比较与 TF-IDF 的 OOF 互补性；不能因为单模型略弱就直接丢弃。

## 4. 外部数据的来源与分布匹配

**假设**：标签可靠、风格接近的少量外部数据，可能优于混合全部数据。

- 从已公开的数据开始，先读来源和模型版本记录，避免上来就自行付费生成。
- 按来源、类别、文本长度、标点与体裁做分层采样；对比官方-only 与几种小规模混合比例。
- 去掉与官方验证文本重复或高度近似的样本；已知同 prompt 的外部样本也应与对应验证组隔离。
- 数据筛选、匹配权重若使用官方标签或统计，应在各折训练部分拟合。全量 train 得出的匹配权重不能无说明地用于 CV。
- 外部数据引入后重新观察 CV 与榜单之间的偏差，不把它们的差值当固定校正项。

## 5. LoRA 与集成

**假设**：外部数据预训练后回到官方数据微调，能兼顾样本量与任务分布；不同表示和数据来源可互补。

- 在前面实验已有依据后，再比较官方-only LoRA 与“外部数据 → 官方数据”两阶段训练。
- 优先控制训练轮数、输入长度、采样比例等直接变量，不先堆模型规模。
- 用 OOF 概率比较简单平均、少量手动权重与原成员组合，记录每个新成员带来的增益。
- 关系建模或组内匹配若值得尝试，同时观察每个 prompt 仅保留部分回答时的敏感性；这仍只是实验近似，不是官方测试布局。

## 记录方式

机器结果留在 `runs/`，有价值的结论可以在此目录新增一页简短笔记：

```text
问题/假设：
与哪个 run 对比、改变了什么：
数据、切分、随机种子：
结果与主要错误变化：
解释、不确定性、下一步：
对应 run 路径：
```

失败或无提升同样值得记录。只做能帮助判断实验结论的实际运行和产物查看，不围绕研究脚本建设测试套件、CI 或审批流程。
