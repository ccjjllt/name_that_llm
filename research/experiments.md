# TF-IDF 与逻辑回归实验 · 2026-11-04

本实验用词汇和字符特征建立模型来源识别的初始参照，关注同厂商型号与短文本的错误分布。使用官方 2,699 条文本、150 个 prompt 和 18 个类别，按 prompt 做五折 StratifiedGroupKFold，shuffle=True，随机种子为 42。

词特征使用 1–2 gram、最多 25,000 维，字符特征使用 3–5 gram、最多 35,000 维。两者均设 min_df=2、sublinear_tf=True，保留大小写。逻辑回归的 C=2.0，max_iter=500。每折向量器与分类器仅在训练部分拟合。

| 指标 | 实测结果 |
|---|---:|
| OOF balanced accuracy | 0.312252 |
| 分折均值 | 0.312248 |
| 分折标准差 | 0.010420 |
| <60 词（555 条） | 0.232902 |
| 60–99 词（767 条） | 0.289523 |
| 100–159 词（723 条） | 0.339890 |
| ≥160 词（654 条） | 0.356587 |

较弱类别的 recall 为 claude-fable-5 的 0.0805、glm-5.3-flash 的 0.1067、glm-5.3 的 0.1667。较强类别包括 gemini-3.1-pro-preview 的 0.6533 和 claude-opus-5 的 0.6267。[完整指标](../runs/20261104T123209Z_tfidf_lr_844505/metrics.json) · [混淆矩阵](../runs/20261104T123209Z_tfidf_lr_844505/confusion_matrix.csv)

文本越短，识别效果越弱，低于 60 词的 BA 比至少 160 词低约 0.124。下一步在相同切分下比较字符 1–5 gram 与简单排版、节奏特征，观察能否补充短文本中的有限词汇证据，并改善弱类别的召回率。社区不同配置或切分下的分数需要另列比较条件。[实验配置](../runs/20261104T123209Z_tfidf_lr_844505/config.json) · [OOF 概率](../runs/20261104T123209Z_tfidf_lr_844505/oof.parquet)
