# PROFILER 多位置打分与下一词对照

同题参照在 C2 的 153 条短文中净改错 4 条，在独立 Claude 的 106 条短文中净改对 0 条。这轮利用单篇正文的 token 损失判断型号。PROFILER 用冻结代理模型对邻近的已观察 token 打分，统计不同位置的损失序列和分布。论文用来源检测 AUC 评价，本实验以 18 类分类和固定底座的净改判为准。[前轮实测](peer_context_20261124.md) · [PROFILER 论文](https://aclanthology.org/2025.emnlp-main.1265/) · [作者代码](https://github.com/MarkGHX/Profiler/blob/main/profiler_utils.py#L61-L114)

## 配对设计

- 使用冻结的 Qwen3‑4B Base，对原文截取最多 160 个 token。当前位置的同一词表分布分别对偏移 −2、−1、0、+1、+2、+3 的正文 token 算负对数概率，以作者代码的实际偏移为准。两组在各位置有完整窗口处共用同一次前向、相同的有效位置和 +1 的分数。
- 两组统计每种可见偏移的损失序列及其位置差分的均值、极值、标准差和中位数。多位置组另加入各列归一化后的两两对称 KL。两组使用同样的 75 槽分类头，下一词组仅开启 +1 的 10 槽。相同的初始化、样本顺序、更新轮次、训练集拟合的标准化流程与正则化。采用 18 类 MLP 适配比赛。
- 与前一轮的 26,733 条输入清单逐条对齐，包括 21,525 条外部训练正文、2,699 条官方训练正文、798 条旧面板、191 条独立 Claude 和 1,520 条留源样本。外部训练后，按官方固定五折做折内适应，另用全官方训练正文适应后预测外部评估面板。稳定 ID 和题号用于对齐和切分。
- 在原版 Sibling Odds 的末段，将各臂 18 类分数按行中心化、截断至 ±3 后融合。沿用已有 C1 从 0、0.15、0.35、0.70 各自锁定全量 BA 最好的权重，打平取小。用 C2 及独立 Claude 的固定轨迹报告两臂相对原版和相互之间的改对、改错、净数、BA、按题重采样区间。另保留所有相同权重的直接对照，并报告不足 100 词的 C2 153 条、Claude 106 条。两组权重均为零时，逐条验证回到原版，同时保留各非零权重对照供诊断。

## 实测结果

双 T4 提取的 26,733 条输入与本地清单及正文顺序哈希一致。用原始分类分数重算 989 条评估预测，结果与远端报告逐条一致。C1 的下一词组在 0 与 0.15 同为 72.13% BA，取 0。多位置组在 0.35 的 BA 为 72.27%，比 C1 原版高 0.14 个百分点。[复算报告](../runs/profiler_20261124/audit/report.json) · [逐条预测](../runs/profiler_20261124/audit/paired_predictions.parquet)
