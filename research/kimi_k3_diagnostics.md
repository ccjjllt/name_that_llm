# kimi-k3 跨族塌陷诊断（方向 C，2026-11-16）

研究问题：我们的 Q8 五折 OOF 上 `kimi-k3` 召回只有 0.500（plain）/ 0.513（`P+.35C+.22G`），而且错误以**跨族**为主（家族准确率 0.513 = 单类召回）。这是训练数据不足、标签污染、长度效应，还是词面特征本身的判别力不够？

判读口径：全部为本项目实测，数据为 `data/q8_protocol/external_expanded.parquet`（238,353 行 / 18 类）、官方 150 prompt 集（2,699 行）与 26,484 更新五折 OOF 概率。样本量类问题看池，迁移类问题看「池训练 → 官方评估」，两者不可混。

## 1. 结论

**kimi 的弱不是数据侧问题，是表征问题。**

| 假说 | 检验 | 结果 | 判定 |
|---|---|---|---|
| 数据量不足 | 池内 kimi 行数 / prompt 数 | 10,674 行 / 8,479 个 prompt（占池 4.5% 行、11.2% prompt） | 否定：样本量与 prompt 多样性都充足 |
| 长度效应 | KS 检验 + 分箱条件召回 | 池内 D=0.048（109 vs 113 词）；官方 D=0.082（p=0.28，不显著）；按长度标准化后召回 0.513→0.527 | 否定：不是长度 |
| 标签污染 / 近重复 | 精确重复、64 前缀、char 5-gram Jaccard | 类内精确重复 0；跨类精确孪生 0；Jaccard>0.8 占比 0.0 | 否定：无污染 |
| 域偏移 | 池训练 → 官方集 AUC vs 官方域内 CV AUC | **0.767 vs 0.776** | 否定：几乎没有域偏移 |
| 特征判别力 | kimi-vs-rest 逻辑回归（char_wb 3–5，prompt 分组 5 折） | 池内 AUC **0.711**（五折 0.703–0.720）；官方域内 AUC **0.776**（AP 0.203） | **成立：词面信号本身弱** |

域内 CV 与跨域迁移几乎同分，这一点很重要：它说明**外部池可以当作族内/单类判别器的训练来源**（这是方向 A 的前提），也说明 kimi 的失败不能靠"再收集同类数据"解决。

## 2. 混淆结构

OOF（`plain_centered_gaussian`）上，150 行真 kimi 的落点：

| 落点 | 行数 |
|---|---:|
| kimi-k3（正确） | 77 |
| gpt-5.5 | 16 |
| claude-fable-5 | 10 |
| glm-5.3-flash | 10 |
| glm-5.3 | 8 |
| gpt-5.6-sol | 7 |
| qwen3.8-max | 6 |
| 其余（claude opus 系 / astra / terra / luna） | 16 |

反向：被判成 kimi 的 107 行里 77 行真是 kimi，**精确率 0.720**。也就是说 kimi 的边界是"收得不够全"，而不是"乱收"。

按 top-2 看，kimi 真实行里 **gpt-5.5 出现在第二名的次数高达 63 次**——kimi 与 gpt-5.5 的边界是最大的单点机会（27 行双向错误）。

长度分层后的条件召回暴露了真正的形状：

| 词数 | kimi 召回 | 其余类平均召回 | 差 |
|---|---:|---:|---:|
| <60 | 0.300 | 0.574 | **−0.274** |
| 60–99 | 0.462 | 0.687 | −0.226 |
| 100–159 | 0.553 | 0.742 | −0.190 |
| ≥160 | 0.767 | 0.762 | +0.004 |

**长文本上 kimi 完全不弱**，差距全部集中在短文本。这与"kimi 的短回答风格与 gpt-5.5 / claude-fable 高度重叠"一致：文本越短，可用的风格证据越少。

## 3. 判别器得分剖面

用池训练的 kimi-vs-rest 判别器给官方 2,699 行打分，按真实类求均值：

| 真实类 | 平均分 |
|---|---:|
| kimi-k3 | 0.575 |
| glm-5.3 | 0.529 |
| glm-5.3-flash | 0.525 |
| gpt-5.5 | 0.524 |
| claude-fable-5 | 0.515 |
| gpt-5.6-sol | 0.476 |
| gemini 系 | 0.26–0.28 |

kimi 只比 glm 两兄弟和 gpt-5.5 高 0.05，而这几个类正是它的主要混淆对象。**判别器无法把 kimi 与这几个类分开**，这不是阈值问题：在池 34% 先验下 AUC 0.711，在官方 5.6% 先验下 AUC 0.767。

按族看 AUC（池内五折，fold0）：gemini 0.974、gpt 0.840、claude 0.799、glm 0.748、qwen 0.713。**gemini 族几乎可以被完美识别，glm 与 qwen 最难**——这与 OOF 上的族内错误分布一致。

## 4. 对后续方向的含义

1. **不要为 kimi 补同类数据**：10.7k 行 / 8.5k prompt 已经足够，域内与跨域 AUC 也几乎相同。
2. **不要做 kimi-vs-rest 硬分类头**：AUC 0.767 的检测器在 5.6% 先验下，取 0.5 阈值会把 35% 的非 kimi 行判成 kimi；按官方分位取阈值只能拿到召回 0.207 / 精确 0.207。
3. **kimi 的结构性机会在 `kimi ↔ gpt-5.5` 的 27 行**，但上限只有 27/(150×18) ≈ +1.0pp；要靠它提分，必须与其它组的收益叠加。
4. **方向 A 的前提被验证**：外池训练 → 官方迁移 AUC 0.767 对域内 0.776，几乎没有损耗。族内/分组判别器完全可以用外池训练，不需要官方标签。
5. **方向 A 的机制有一个结构性缺口**：现有条件重排只在 top-1 与 top-2 同族时触发，而 kimi 与 qwen 是单标签族，永远不会触发。而 kimi 恰好是最差的类。要覆盖它，必须增加"分组级"而不是"族内级"的重排（例如把 `{glm-5.3, glm-5.3-flash, claude-fable-5}` 定义为一个硬分组，或允许单标签族参与）。

## 5. 误差配对的量级（用同一份混淆矩阵算出）

balanced accuracy 的每类权重是 1/18，每类约 150 行，所以**修正一行 ≈ +0.037pp**，修正 100 行 ≈ +3.7pp。当前 2,699 行里共 832 行错误。

| 组 | 组内错误行数 | 完美组内判别器的 BA 上限 |
|---|---:|---:|
| `{glm-5.3, glm-5.3-flash}` | 74 | +2.74pp |
| `{gemini-3.6, 3.7, 3.8 flash}` | 127 | +4.70pp |
| `{gpt-5.5, 5.6-luna, 5.6-sol, 5.6-terra, 6-astra}` | 94 | +3.48pp |
| `{claude 五兄弟}` | 98 | +3.63pp |
| **`{glm-5.3, glm-5.3-flash, claude-fable-5}`** | **191** | **+7.07pp** |
| `{kimi-k3, gpt-5.5}` | 27 | +1.00pp |

最大的单块不是"glm 对"（74 行），而是 **glm 两兄弟 + claude-fable-5 的三元组（191 行）**：`glm-5.3↔claude-fable-5` 65 行、`glm-5.3-flash↔claude-fable-5` 52 行，都是**跨族**错误，现有族内重排碰不到。

这些是"完美判别器"的上限。真实判别器按 AUC 0.75–0.80 折算大约能吃到 25–40%，即 2–3pp 量级——仍然远大于此前在 q8v5 槽位上测到的 −0.003。
